## Image

| Property | Type | Default | Description |
|---|---|---|---|
| `src` | `string` | **Required** | Image URL. |
| `alt` | `string` | **Required** | Alternative text. |
| `span` | `number` | - | Column span. |

## Figure

| Property | Type | Default | Description |
|---|---|---|---|
| `src` | `string` | **Required** | Image URL. |
| `alt` | `string` | **Required** | Alternative text. |
| `caption` | `string` | - | Image caption. |
| `credit` | `string` | - | Photographer or source, rendered in small caps. |
| `span` | `number` | - | Column span. |

## PullQuote

| Property | Type | Default | Description |
|---|---|---|---|
| `weight` | `'High' \| 'Medium'` | `'High'` | Visual weight。 |
| `span` | `number` | - | Column span within the Section grid. |
| `spanAllColumns` | `boolean` | `false` | Span every column inside a multi-column BodyText. |
| `author` | `string` | - | Quote attribution. |
| `align` | `'left' \| 'center'` | `'left'` | Text alignment. |

### Standalone usage

<ComponentDemo
  title="Standalone pull quote"
  code={[
    '<PullQuote author="Senior Cabinet Official">',
    '  We have lobbied for this kind of clarity for the better part of a decade.',
    '</PullQuote>',
  ].join('\n')}
>
  <PullQuote author="Senior Cabinet Official">
    {'We have lobbied for this kind of clarity for the better part of a decade.'}
  </PullQuote>
</ComponentDemo>

### Spanning columns inside multi-column BodyText

<ComponentDemo
  title="Pull quote across text columns"
  code={[
    '<BodyText columns={3}>',
    '  <p>After eleven consecutive days of negotiation, delegates announced a sweeping framework.</p>',
    '  <PullQuote spanAllColumns author="Margarethe Lindqvist">A long argument that finally became a conversation.</PullQuote>',
    '  <p>Markets reacted with measured optimism as the agreement moved toward ratification.</p>',
    '</BodyText>',
  ].join('\n')}
>
  <BodyText columns={3}>
    <p>
      {'After eleven consecutive days of negotiation, delegates announced a sweeping framework.'}
    </p>

      {'A long argument that finally became a conversation.'}
    </PullQuote>
    <p>
      {'Markets reacted with measured optimism as the agreement moved toward ratification.'}
    </p>
  </BodyText>
</ComponentDemo>
