## Footer

| 属性 | 类型 | 默认值 | 说明 |
|---|---|---|---|
| copyright | string | — | 版权文字 |
| edition | string | — | 版次 |
| links | `Array<{ label, href }>` | — | 底部链接 |

<ComponentDemo
  title="Publication footer"
  code={[
    '<Footer',
    '  copyright="© 2026 The Daily Chronicle"',
    '  edition="Late City Edition"',
    '  links={[',
    '    { label: "Archive", href: "#archive" },',
    '    { label: "Contact", href: "#contact" },',
    '  ]}',
    '/>',
  ].join('\n')}
>
  <Footer
    copyright="© 2026 The Daily Chronicle"
    edition="Late City Edition"
    links={[
      { label: 'Archive', href: '#archive' },
      { label: 'Contact', href: '#contact' },
    ]}
  />
</ComponentDemo>

## NewsSidebar

| 属性 | 类型 | 默认值 | 说明 |
|---|---|---|---|
| span | number | 6 | 占用列数 |
| position | "left" \| "right" | "right" | 位置 |
| divider | boolean | false | 是否显示分隔线 |

<ComponentDemo
  title="Article with news sidebar"
  code={[
    '<Layout columns={24} maxWidth="none" padding="0">',
    '  <Section columns={24} gap="1.5rem">',
    '    <Article span={18}><Headline weight="Low" as="h3">Council Publishes Housing Programme</Headline><BodyText><p>The first phase begins with six publicly owned sites.</p></BodyText></Article>',
    '    <NewsSidebar span={6} divider><Kicker>AT A GLANCE</Kicker><BodyText weight="Low"><p>2,400 homes · six sites · three phases</p></BodyText></NewsSidebar>',
    '  </Section>',
    '</Layout>',
  ].join('\n')}
>
  <Layout columns={24} maxWidth="none" padding="0">
    <Section columns={24} gap="1.5rem">
      <Article span={18}>
        <Headline weight="Low" as="h3">{'Council Publishes Housing Programme'}</Headline>
        <BodyText><p>{'The first phase begins with six publicly owned sites.'}</p></BodyText>
      </Article>
      <NewsSidebar span={6} divider>
        <Kicker>AT A GLANCE</Kicker>
        <BodyText weight="Low"><p>{'2,400 homes · six sites · three phases'}</p></BodyText>
      </NewsSidebar>
    </Section>
  </Layout>
</ComponentDemo>

## BreakingNewsBanner

| 属性 | 类型 | 默认值 | 说明 |
|---|---|---|---|
| label | string | "BREAKING" | 标签文字 |
| children | ReactNode | — | 新闻内容 |

<ComponentDemo
  title="Breaking-news banner"
  code={[
    '<BreakingNewsBanner label="BREAKING">',
    '  Rail services resume after overnight signaling repairs',
    '</BreakingNewsBanner>',
  ].join('\n')}
>
  <BreakingNewsBanner label="BREAKING">
    {'Rail services resume after overnight signaling repairs'}
  </BreakingNewsBanner>
</ComponentDemo>
