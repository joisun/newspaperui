## API

| Property      | Type                            | Default    | Description                       |
| --------- | ------------------------------- | --------- | -------------------------- |
| title     | string                          | Required      | Publication title.                 |
| variant   | classic, blackletter, or modern | classic   | Visual style.                 |
| as        | h1 through h6                    | h1        | Semantic heading level for the publication title.       |
| kicker    | string                          | -         | Kicker above the publication title.           |
| edition   | string                          | -         | Edition.                     |
| date      | string                          | -         | Date。                     |
| price     | string                          | -         | Price.                     |

## Usage guidance

Masthead spans all Section columns by default. Keep the default <code>h1</code> for a page-level masthead; when nested in documentation, cards, or composed examples, use <code>as</code> to preserve a continuous heading hierarchy.
