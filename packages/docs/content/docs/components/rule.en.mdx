## API

| Property | Type | Default | Description |
|---|---|---|---|
| `variant` | `'hairline' \| 'double' \| 'thick'` | `'hairline'` | Rule style. |
| `orientation` | `'horizontal' \| 'vertical'` | `'horizontal'` | Orientation. |
| `span` | `number` | - | Column span when horizontal. By default it spans from 1 to -1. |
| `className` | `string` | - | Custom CSS class name. |
| `style` | `CSSProperties` | - | Custom inline styles. |

## Usage guidance

Rule spans the full Section by default; use `span` to constrain its width. Vertical rules work well between flex or grid columns.
