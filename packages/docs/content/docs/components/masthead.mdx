## API

| 属性      | 类型                            | 默认值    | 说明                       |
| --------- | ------------------------------- | --------- | -------------------------- |
| title     | string                          | 必填      | 报名文字。                 |
| variant   | classic, blackletter 或 modern | classic   | 视觉风格。                 |
| as        | h1 至 h6                        | h1        | 报名的语义标题级别。       |
| kicker    | string                          | -         | 报名上方的小标。           |
| edition   | string                          | -         | 版次。                     |
| date      | string                          | -         | 日期。                     |
| price     | string                          | -         | 售价。                     |

## 使用建议

Masthead 默认跨越 Section 的全部列。页面级报头保留默认 <code>h1</code>；嵌套在文档、卡片或组合示例中时，通过 <code>as</code> 选择与上下文连续的标题级别。
