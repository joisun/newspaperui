## API

| 属性 | 类型 | 默认值 | 说明 |
|---|---|---|---|
| `variant` | `'hairline' \| 'double' \| 'thick'` | `'hairline'` | 线型。 |
| `orientation` | `'horizontal' \| 'vertical'` | `'horizontal'` | 方向。 |
| `span` | `number` | - | 横向时占多少列。缺省时 1 / -1 全跨。 |
| `className` | `string` | - | 自定义 CSS 类名。 |
| `style` | `CSSProperties` | - | 自定义内联样式。 |

## 垂直方向

<ComponentDemo
  title="Vertical column divider"
  code={[

    <Rule variant="hairline" orientation="vertical" />

  </div>
</ComponentDemo>

## 使用建议

Rule 在 Section 内默认全跨；使用 `span` 限制栏宽。垂直 Rule 适合 flex 或 grid 栏间分隔。
