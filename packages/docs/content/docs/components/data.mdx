## Folio

| 属性 | 类型 | 默认值 | 说明 |
|---|---|---|---|
| page | string | — | 页码，如 "A2" |
| section | string | — | 版名，如 "要闻" |
| date | string | — | 日期 |
| publication | string | — | 报名 |

<ComponentDemo
  title="Section folio"
  code={[
    '<Folio',
    '  page="A2"',
    '  section="National"',
    '  publication="The Daily Chronicle"',
    '  date="Tuesday, May 19, 2026"',
    '/>',
  ].join('\n')}
>
  <Folio
    page="A2"
    section="National"
    publication="The Daily Chronicle"
    date="Tuesday, May 19, 2026"
  />
</ComponentDemo>

## IndexBox

| 属性 | 类型 | 默认值 | 说明 |
|---|---|---|---|
| title | string | "Inside" | 标题 |
| items | `Array<{ page, title, headline? }>` | — | 索引条目 |

<ComponentDemo
  title="Front-page index"
  code={[
    '<IndexBox',
    '  title="Inside today"',
    '  items={[',
    '    { page: "A2", title: "National", headline: "Mayors agree shared housing targets" },',
    '    { page: "B1", title: "Business", headline: "Markets welcome infrastructure plan" },',
    '    { page: "C3", title: "Culture", headline: "Archive opens a new public gallery" },',
    '  ]}',
    '/>',
  ].join('\n')}
>
  <IndexBox
    title="Inside today"
    items={[
      { page: 'A2', title: 'National', headline: 'Mayors agree shared housing targets' },
      { page: 'B1', title: 'Business', headline: 'Markets welcome infrastructure plan' },
      { page: 'C3', title: 'Culture', headline: 'Archive opens a new public gallery' },
    ]}
  />
</ComponentDemo>

## Factbox

| 属性 | 类型 | 默认值 | 说明 |
|---|---|---|---|
| title | string | — | 标题 |
| span | number | — | 跨栏数 |
| variant | "default" \| "highlight" \| "timeline" | "default" | 样式变体 |

<ComponentDemo
  title="Highlighted factbox"
  code={[
    '<Factbox title="Programme at a glance" variant="highlight">',
    '  <ul>',
    '    <li>Six regional projects</li>',
    '    <li>Ten-year delivery window</li>',
    '    <li>Annual independent review</li>',
    '  </ul>',
    '</Factbox>',
  ].join('\n')}
>
  <Factbox title="Programme at a glance" variant="highlight">
    <ul>
      <li>Six regional projects</li>
      <li>Ten-year delivery window</li>
      <li>Annual independent review</li>
    </ul>
  </Factbox>
</ComponentDemo>

## RelatedArticles

| 属性 | 类型 | 默认值 | 说明 |
|---|---|---|---|
| title | string | "Related" | 标题 |
| articles | `Array<{ title, href, category? }>` | — | 文章列表 |

<ComponentDemo
  title="Related coverage"

    '    { category: "Opinion", title: "The case for patient delivery", href: "#story-opinion" },',
    '  ]}',
    '/>',
