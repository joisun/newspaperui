## Image

| 属性 | 类型 | 默认值 | 说明 |
|---|---|---|---|
| `src` | `string` | **必填** | 图片 URL。 |
| `alt` | `string` | **必填** | 替代文本。 |
| `span` | `number` | - | 跨栏数。 |

## Figure

| 属性 | 类型 | 默认值 | 说明 |
|---|---|---|---|
| `src` | `string` | **必填** | 图片 URL。 |
| `alt` | `string` | **必填** | 替代文本。 |
| `caption` | `string` | - | 图片说明。 |
| `credit` | `string` | - | 摄影师/来源（small-caps 渲染）。 |
| `span` | `number` | - | 跨栏数。 |

## Video

| 属性 | 类型 | 默认值 | 说明 |
|---|---|---|---|
| `src` | `string` | **必填** | 视频 URL。 |
| `poster` | `string` | - | 封面图 URL。 |
| `caption` | `string` | - | 视频说明。 |
| `credit` | `string` | - | 来源。 |
| `controls` | `boolean` | `true` | 显示播放控件。 |
| `span` | `number` | - | 跨栏数。 |

## PullQuote

| 属性 | 类型 | 默认值 | 说明 |
|---|---|---|---|
| `weight` | `'High' \| 'Medium'` | `'High'` | 视觉权重。 |
| `span` | `number` | - | 在 Section 栅格内跨栏。 |
| `spanAllColumns` | `boolean` | `false` | 在多栏 BodyText 内跨所有栏。 |
| `author` | `string` | - | 引用来源。 |
| `align` | `'left' \| 'center'` | `'left'` | 文本对齐。 |

### 独立使用

<ComponentDemo
  title="Standalone pull quote"

### 在多栏 BodyText 内跨栏

<ComponentDemo
  title="Pull quote across text columns"
  code={[

    '  <p>Markets reacted with measured optimism as the agreement moved toward ratification.</p>',
    '</BodyText>',
  ].join('\n')}
>
  <BodyText columns={3}>

    <PullQuote spanAllColumns author="Margarethe Lindqvist">
      {'A long argument that finally became a conversation.'}
    </PullQuote>

      {'Markets reacted with measured optimism as the agreement moved toward ratification.'}
    </p>
  </BodyText>
</ComponentDemo>
