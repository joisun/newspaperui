## Article

### Article API

| Property | Type | Default | Description |
|---|---|---|---|
| `span` | `number` | - | Number of columns to span (≤ Section.columns). Defaults to full width. |
| `breakable` | `boolean` | `true` | Allow page breaks when printing. |
| `className` | `string` | - | Custom CSS class name. |
| `style` | `CSSProperties` | - | Custom inline styles. |
| `children` | `ReactNode` | **Required** | Article content. |

## Layer

### Layer API

| Property | Type | Default | Description |
|---|---|---|---|
| `position` | `'absolute' \| 'fixed' \| 'sticky'` | `'absolute'` | CSS position property. |
| `top` | `string \| number` | - | Distance from the top. |
| `left` | `string \| number` | - | Distance from the left. |
| `right` | `string \| number` | - | Distance from the right. |
| `bottom` | `string \| number` | - | Distance from the bottom. |
| `zIndex` | `number` | - | z-index layer. |
| `children` | `ReactNode` | **Required** | Floating layer content. |

### Floating pull quote with Layer

The parent container needs `position: relative`.

<ComponentDemo
  title="Layered pullout note"
  code={[
    '<div style={{ position: "relative", minHeight: "13rem", paddingRight: "10rem" }}>',
