## Layout

| Property | Type | Default | Description |
|---|---|---|---|
| columns | number | 24 | Total grid columns |
| maxWidth | string | "1280px" | Maximum width |
| padding | string | "var(--nui-space-6)" | Padding |
| theme | "light" \| "dark" | — | Theme |

## Section

| Property | Type | Default | Description |
|---|---|---|---|
| columns | number | — | Grid columns (≤ Layout.columns) |
| gap | string | "var(--nui-gutter)" | Gap |
| breakable | boolean | true | Whether page breaks are allowed |
| divider | "none" \| "top" \| "bottom" \| "both" | "none" | Divider |
| responsive | `{ sm?: number; md?: number; lg?: number }` | — | Responsive column count |

## Article

| Property | Type | Default | Description |
|---|---|---|---|
| span | number | — | Column span |
| breakable | boolean | true | Whether page breaks are allowed |

## Layer

| Property | Type | Default | Description |
|---|---|---|---|
| position | "absolute" \| "fixed" \| "sticky" | "absolute" | Positioning mode |
| top / left / right / bottom | string \| number | — | Position |
| zIndex | number | — | Layer order |
