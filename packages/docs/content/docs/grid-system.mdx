---
title: 栅格系统
description: 24 列 CSS Grid
---

`Layout`、`Section` 和 `Article` 组成 24 列 CSS Grid，覆盖 2 / 3 / 4 / 6 / 8 / 12 等常见栏宽组合。

## Layout API

| 属性 | 类型 | 默认值 | 说明 |
|---|---|---|---|
| `columns` | `number` | `24` | 栅格总列数。决定子 Section 的最大 columns。 |
| `maxWidth` | `string` | `'1280px'` | 页面最大宽度。 |
| `padding` | `string` | `'var(--nui-space-6)'` | 页面内边距。 |
| `theme` | `'light' \| 'dark'` | - | 强制主题；省略时跟随 documentElement.dataset.theme。 |
| `children` | `ReactNode` | **必填** | 子内容（通常是若干 Section）。 |

## Section API

| 属性 | 类型 | 默认值 | 说明 |
|---|---|---|---|
| `columns` | `number` | **必填** | Section 内部栅格列数（≤ Layout.columns）。 |
| `gap` | `string` | `'var(--nui-gutter)'` | 栏间间距。 |
| `breakable` | `boolean` | `true` | 允许打印时跨页断开。 |
| `divider` | `'none' \| 'top' \| 'bottom' \| 'both'` | `'none'` | 上下方向的 hairline 分隔线。 |

## Article API

| 属性 | 类型 | 默认值 | 说明 |
|---|---|---|---|
| `span` | `number` | - | 跨多少列（0 &lt; span ≤ Section.columns）。 |
| `breakable` | `boolean` | `true` | 允许打印时跨页断开。 |
| `children` | `ReactNode` | **必填** | 文章内容。 |

## 用法示例

### 8 + 16 跨栏

<ComponentDemo
  title="Eight + sixteen"
  code={[
    '<Layout columns={24} maxWidth="none" padding="0">',
    '  <Section columns={24} gap="1.5rem">',
    '    <Article span={8}>',
    '      <Kicker>BRIEFING</Kicker>',
    '      <Headline weight="Low" as="h3">Three items before noon</Headline>',
    '      <BodyText><p>Committee hearings begin with transport and housing.</p></BodyText>',
    '    </Article>',
    '    <Article span={16}>',
    '      <Kicker>LEAD</Kicker>',
    '      <Headline weight="Medium" as="h3">Regional Budget Places Infrastructure First</Headline>',
    '      <BodyText columns={2}><p>The ten-year programme links rail, schools, and public housing.</p></BodyText>',
    '    </Article>',
    '  </Section>',
    '</Layout>',
  ].join('\n')}
>
  <Layout columns={24} maxWidth="none" padding="0">
    <Section columns={24} gap="1.5rem">
      <Article span={8}>
        <Kicker>BRIEFING</Kicker>
        <Headline weight="Low" as="h3">{'Three items before noon'}</Headline>
        <BodyText>
          <p>{'Committee hearings begin with transport and housing.'}</p>
        </BodyText>
      </Article>
      <Article span={16}>
        <Kicker>LEAD</Kicker>
        <Headline weight="Medium" as="h3">
          {'Regional Budget Places Infrastructure First'}
        </Headline>
        <BodyText columns={2}>
          <p>{'The ten-year programme links rail, schools, and public housing.'}</p>
        </BodyText>
      </Article>
    </Section>
  </Layout>
</ComponentDemo>
