## Visual weight mapping

All text component styles are driven by <code>visualWeights</code> data and stay synchronized when the theme changes.

| Component | Visual weight | Font | Size | Weight | Line height |
| -------- | ------ | -------- | ---- | ---- | ---- |
| Headline | High   | Display  | 48px | 700  | 1.05 |
| Headline | Medium | Headline | 32px | 700  | 1.15 |
| Headline | Low    | Headline | 22px | 600  | 1.25 |
| Subhead  | High   | Headline | 22px | 400  | 1.35 |
| Subhead  | Medium | Headline | 18px | 400  | 1.4  |
| BodyText | High   | Body     | 17px | 400  | 1.65 |
| BodyText | Medium | Body     | 16px | 400  | 1.6  |
| BodyText | Low    | Body     | 15px | 400  | 1.55 |
