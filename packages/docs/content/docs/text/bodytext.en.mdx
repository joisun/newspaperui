## API

| Property | Type | Default | Description |
|---|---|---|---|
| weight | "High" \| "Medium" \| "Low" | "Medium" | Visual weight |
| columns | 1 \| 2 \| 3 \| 4 | 1 | Multi-column text flow |
| columnWidth | string | — | Target column width |
| columnFill | "auto" \| "balance" | "balance" | Column fill mode |
| dropCap | boolean | false | Drop caps |
| span | number | — | Column span |

## Multi-column text flow

<ComponentDemo
  title="Balanced three-column body"
  code={[
    '<BodyText columns={3}>',
    '  <p>The first phase reconnects the station with the civic quarter.</p>',
    '  <p>A second route will serve the university and western suburbs.</p>',

  </BodyText>
</ComponentDemo>

## Typography details

Enabled by default:
- No space between paragraphs, with a 1em first-line indent from the second paragraph
- Old-style figures, with descenders on 3/5/7
- Hanging punctuation for quotation marks
- Column rules using a hairline divider
