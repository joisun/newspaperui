## API

| 属性 | 类型 | 默认值 | 说明 |
|---|---|---|---|
| variant | "block" \| "inline" | "block" | 变体 |
| weight | "High" \| "Medium" | "Medium" | 视觉权重 |
| span | number | — | 跨栏数 |
| cite | string | — | 引用来源 URL |

## Block Quote

左缩进 1.5em，**无 border-left**（报纸传统）。

## Inline Quote

渲染为 `<em>` italic，不加引号（报纸传统）。
