## API

| 属性 | 类型 | 默认值 | 说明 |
|---|---|---|---|
| variant | "block" \| "inline" | "block" | 变体 |
| weight | "High" \| "Medium" | "Medium" | 视觉权重 |
| span | number | — | 跨栏数 |
| cite | string | — | 引用来源 URL |

## Block Quote

<ComponentDemo
  title="Block quotation"
  code={[
    '<Quote variant="block" weight="High" cite="https://example.com/public-record">',
    '  The agreement gives every region a measurable route from policy to delivery.',
    '</Quote>',
  ].join('\n')}
>
  <Quote variant="block" weight="High" cite="https://example.com/public-record">
    {'The agreement gives every region a measurable route from policy to delivery.'}
  </Quote>
</ComponentDemo>

## Inline Quote

<ComponentDemo
  title="Inline quotation"
  code={[
    '<BodyText>',

    '</BodyText>',
  ].join('\n')}
>
  <BodyText>
    <p>
      {'The chair described the vote as '}
