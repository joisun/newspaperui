## Byline

| Property | Type | Description |
|---|---|---|
| children | ReactNode | For example, "By Alice Smith" |

## Dateline

| Property | Type | Description |
|---|---|---|
| children | ReactNode | For example, "LONDON —" |

## Caption

| Property | Type | Description |
|---|---|---|
| credit | string | Photographer credit, rendered in small caps |
| children | ReactNode | Caption text |

## AuthorCard

| Property | Type | Description |
|---|---|---|
| name | string | Name |
| role | string | Role |
| bio | string | Biography |
| avatar | string | Avatar URL |
| email | string | Email |

## JumpLine

| Property | Type | Description |
|---|---|---|
| direction | "to" \| "from" | Direction |
| page | string | Destination page, such as "A6" |
