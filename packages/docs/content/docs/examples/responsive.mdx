响应式布局使用 CSS media query 与 container query，不读取 JavaScript viewport。

## 断点说明

| 断点    | 宽度           | 栏数建议 | 说明                     |
| ------- | -------------- | -------- | ------------------------ |
| Mobile  | 小于 768px     | 1 栏     | 单栏堆叠，核心内容优先   |
| Tablet  | 768px - 1024px | 12 列    | 主报道全宽，辅助内容双栏 |
| Desktop | 大于 1024px    | 24 列    | 6 + 12 + 6 完整版面      |

## 实施原则

- 内容优先级决定 Mobile 顺序，不依赖视觉上的 CSS order 反转。
- 栅格变化写在 CSS 中，避免 render 阶段读取 viewport。
- 窄屏正文回到单栏，table 与 source 仅在自身容器内滚动。
