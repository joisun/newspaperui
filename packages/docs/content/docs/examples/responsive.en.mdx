Responsive layouts use CSS media queries and container queries without reading the JavaScript viewport.

## Breakpoint guide

| Breakpoint | Width       | Suggested columns | Description                     |
| ------- | -------------- | -------- | ------------------------ |
| Mobile  | Below 768px     | 1 column     | Single-column stack with priority content first   |
| Tablet  | 768px - 1024px | 12 columns    | Full-width lead story with two-column supporting content |
| Desktop | Above 1024px    | 24 columns    | Complete 6 + 12 + 6 layout      |

## Implementation principles

- Content priority determines the mobile order; do not rely on visually reversing CSS order.
- Express grid changes in CSS instead of reading the viewport during render.
- Return body copy to one column on narrow screens; tables and source code scroll only within their own containers.
